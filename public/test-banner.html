Note sur les données de test

Les 5 numéros tirés sont partagés entre toutes les grilles. Il est physiquement impossible d'avoir simultanément grille 1 → 4 matchs et grille 2 → 3 matchs (cela nécessiterait 7 numéros distincts dans 5 boules). Les scénarios ci-dessous représentent les combinaisons les plus riches réalisables avec les grilles fixes du syndicat.
Ouvrir la console (F12) pour les logs détaillés.
